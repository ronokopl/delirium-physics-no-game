Delirium Physics: No Game Needed  (ready-built for Windows)
============================================================

Double-click "Play Delirium (no game).bat". No game assets are required.

If the room is slow or will not start, try:  delirium-room.exe --safe

This is a MODIFIED version of Delirium Physics, not the original. It runs on
stand-in numbers, a stand-in body and its own animations, so Homer moves
differently from the real Delirium.

It is open source (GPL-3.0-only, see LICENSE). The complete source code for
exactly this build, and how to change and rebuild it, is at:

  https://github.com/ronokopl/delirium-physics-no-game
